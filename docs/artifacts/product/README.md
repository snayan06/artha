# Product artifacts

This directory holds dated product reviews, usability audits and implementation
contracts. Product source-of-truth requirements remain in the parent `docs/`
directory.

## Safety

- Use fictional or aggregate, redacted evidence only.
- Never commit raw exports, real transaction text, names, account details,
  balances, credentials or provider secrets.
- Link every artifact from this index and the parent artifact index.
