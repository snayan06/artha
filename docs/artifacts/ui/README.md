# UI artifacts

Store sanitized UI evidence here, grouped by milestone when the collection
grows. A useful V1 set should include:

- onboarding at 390 px;
- Home in light and dark mode;
- text-entry review and manual-entry form;
- shared household balances;
- Assistant inline chart/table UI;
- a 1440 px desktop view.

Screenshots must use fictional household members and accounts. Record the
viewport and theme in the filename or adjacent Markdown note.
